# Build a Proofreading Tool

Build a proofreading tool that analyzes arrays of words for palindromes and repeated arrays.

## Technologies

Uses JavaScript.

## Deployment

Copy `script.js` into the text editor of your choice.  If using terminal, use the command `node script.js` to run the code.
